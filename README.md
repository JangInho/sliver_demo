## Installation
To get started with this Flutter project, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/JangInho/sliver_demo.git
   cd sliver_demo
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```
