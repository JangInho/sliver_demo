## 🛠️ Installation

To get started with the project, make sure you have [Flutter](https://flutter.dev/docs/get-started/install) installed on your machine. Then, follow these steps:

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd sliver_demo
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the application:
   ```bash
   flutter run
   ```
