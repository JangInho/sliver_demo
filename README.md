## 🚀 Getting Started

To get started with this Flutter application, follow these steps:

1. **Install Flutter**: Make sure you have Flutter installed on your system. You can follow the official installation guide [here](https://docs.flutter.dev/get-started/install).

2. **Clone the Repository**: 
   ```bash
   git clone https://github.com/JangInho/sliver_demo.git
   cd sliver_demo
   ```

3. **Install Dependencies**: Run the following command to install the dependencies:
   ```bash
   flutter pub get
   ```

4. **Run the Application**: Launch the app using:
   ```bash
   flutter run
   ```
