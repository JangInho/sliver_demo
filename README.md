## Installation 🛠️
To set up your environment for Flutter development, follow these steps:

1. Install Flutter by following the installation guide on the [official website](https://flutter.dev/docs/get-started/install).
2. Clone this repository:
   ```bash
   git clone https://github.com/JangInho/sliver_demo.git
   cd sliver_demo
   ```
3. Install the dependencies:
   ```bash
   flutter pub get
   ```

## Usage 🏁
To run the application locally, use the following command:
```bash
flutter run
```

## Directory Structure 📁
Here is a brief overview of the project’s directory structure:

